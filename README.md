# Local Business Website Templates

A collection of modern, responsive website templates for small and local businesses.

## Templates
- Bakery / Cake Shop
- Restaurant / Cafe
- Hotel / Guest House
- Salon / Beauty Parlour
- Gym / Fitness Studio
- Boutique
- Photography Studio
- Interior Design
- Coaching
- Service Business

Each template is designed to be customized for a real client with their branding, photos, services, contact details, domain, WhatsApp link, Google Maps location and QR code.
