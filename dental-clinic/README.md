# Dental Clinic Website Template

Modern responsive website template for a local dental clinic.

## Includes
- Appointment CTA
- Dental services
- Dentist profile
- Call and WhatsApp buttons
- Clinic timings and location
- Mobile responsive design
- SEO metadata

## Run locally
From the repository root:

python3 -m http.server 8000

Open:

http://localhost:8000/dental-clinic/

## Customize
Replace the clinic name, dentist details, services, address, phone number, WhatsApp number, timings and branding with the client's information.
