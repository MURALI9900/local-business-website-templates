# Gym / Fitness Studio Template

A bold responsive static website template for gyms, fitness studios, personal trainers and performance centers.

## Includes
- Gym landing page
- Strength, conditioning, personal training and group programs
- Sample pricing
- Training philosophy section
- Coach profiles
- Free-trial and WhatsApp booking CTAs
- Contact details and opening hours
- Mobile responsive layout
- SEO metadata

## Customization
Replace the sample brand, programs, prices, coach details, address and contact information in index.html. Replace the WhatsApp number with the client's real number and replace image placeholders with real photographs.

## Deployment
Static HTML/CSS site suitable for GitHub Pages, Netlify, Vercel or similar hosting.
