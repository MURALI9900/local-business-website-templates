# Hotel / Guest House Website Template

An elegant responsive website starter for hotels, boutique stays, guest houses and homestays.

### Includes
- Hero section with booking CTA
- Room cards and pricing
- Amenities / experience section
- Gallery
- WhatsApp booking
- Call and email actions
- Address and check-in details
- SEO-ready metadata
- Mobile responsive layout

All hotel details in this demo are fictional placeholders and should be replaced before client delivery.
