# Multi-Speciality Clinic Website Template

Responsive website template for a modern multi-speciality clinic.

## Includes
- Departments and medical services
- Doctor profiles
- Appointment CTA
- Diagnostics and patient services
- Emergency contact
- Call and WhatsApp buttons
- Clinic timings and location
- Responsive mobile design

## Run locally
From the repository root:

python3 -m http.server 8000

Open:

http://localhost:8000/multi-speciality-clinic/

## Customize
Replace clinic name, doctors, departments, services, contact details, timings and branding.
