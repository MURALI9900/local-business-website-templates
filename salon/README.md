# Salon / Beauty Parlour Template

A polished, responsive static website template for salons, beauty parlours, makeup studios and hair studios.

## Includes
- Modern salon landing page
- Hair, skin, nails and makeup services
- Sample pricing
- About / brand story section
- Team section
- Gallery
- WhatsApp booking CTA
- Phone and email contact
- Address and opening hours
- Responsive mobile layout
- SEO metadata

## Customization
Replace the sample brand, text, pricing, address, team details and contact information in index.html.

Replace the WhatsApp number in the booking links with the client's real number.

The visual gallery blocks can be replaced with real salon photographs.

## Run locally
Open index.html directly in a browser.

## Deployment
This is a static HTML/CSS site and can be deployed using GitHub Pages, Netlify, Vercel or similar static hosting.
